# Hooks

Custom React hooks for state management and data fetching.

## Files

- `useAvirato.ts` - Avirato reservation data hooks
- `useLastApp.ts` - Last.app messaging hooks
- `useCalendar.ts` - Calendar booking hooks
- `useSync.ts` - Sync status hooks
- `use-mobile.tsx` - Mobile responsive detection
- `use-toast.ts` - Toast notification hook

## Conventions

- All hooks must start with `use` prefix
- Keep hooks focused on a single concern
- Handle loading and error states within hooks
